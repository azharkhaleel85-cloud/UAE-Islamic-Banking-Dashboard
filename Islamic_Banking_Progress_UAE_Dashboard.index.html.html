Data integrity and limitations. The uploaded workbook includes bank-level assets, CET1 and internal capital generation, but does not provide a product-level breakdown (Murabaha, Ijara, Sukuk). A product-mix pie chart would require verified financing-by-product figures and is intentionally not fabricated. United Arab Bank lacks 2020 assets; consistent-growth comparisons exclude that bank across the entire period. Possible parent–subsidiary overlaps and changing consolidation status (including Ajman Bank) mean reported asset sums are illustrative sample totals, not official UAE sector totals.
ℹ️ About This Dashboard · Methods, sources & responsible AI

Purpose: Master's-level academic prototype assessing Islamic banking progress in the UAE, 2020–2025. Source: uploaded UAEBanks_FitchData_2100109.xlsx, specifically the “Islamic Banks” and “Conventional Banks” worksheets; original bank names, Fitch IDs, reporting years and selected financial fields were preserved. Student ID: 2100109.

Responsible AI disclosure: This dashboard was developed with OpenAI ChatGPT as a coding and data-visualization assistant. It can be hosted or shared through Claude.ai if supported, but it would be inaccurate to claim Claude authored the code without actually using Claude. No financial observations were generated by AI.

Summarized AI prompts:

  1. Build a self-contained, professional interactive UAE Islamic banking dashboard from the uploaded Fitch Connect workbook.
  2. Show asset trends, Islamic-versus-conventional comparisons, bank rankings, year-on-year growth and CET1 indicators.
  3. Add interactive year, banking-model and bank filters, sortable searchable tables and export functionality.
  4. Document source limitations, missing product-level data, consolidation risks and responsible AI usage.

Verification and calculations: Asset totals are summed from provided bank-year observations. Growth = (current / prior − 1) × 100. Asset mix = selected Islamic assets / selected combined assets × 100. CET1 chart uses the arithmetic mean of nonmissing bank ratios; this is not a system-wide capital adequacy measure. For growth analyses, banks must have all selected-year observations to avoid changes in sample composition. Results should be independently cross-checked against the workbook and Fitch Connect before academic submission.

Technology and privacy: HTML, CSS and native JavaScript/SVG; no external libraries, CDN, trackers, APIs or network requests. The dataset is embedded locally within this file. No data is transmitted to an external server by the dashboard itself.
